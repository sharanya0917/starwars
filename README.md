# Star Wars Game

A fun Star Wars-themed game built with Python.

## Features
- Interactive Star Wars battles
- Character selection
- Combat system
- Score tracking

## How to Play

1. Run the game:
   ```bash
   python starwars.py
   ```

2. Choose your character
3. Battle enemies and earn points
4. Try to reach the highest score!

## Requirements
- Python 3.6+
- No external dependencies
